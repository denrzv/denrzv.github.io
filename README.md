# denrzv.github.io

Home of **The Bogosort Appreciation Society**: a small, deliberately old-school page about the
world's most optimistic sorting algorithm. It lives in [`site/`](site/) and is published to
<https://denrzv.github.io/> by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on
every push to `master`.

## What used to be here

- **Bloom Flowers** (the SiteSkin reference integration) was served here as a temporary stopgap.
  It now lives at <https://funflowers.online>; its source is
  [denrzv/bloom-flowers](https://github.com/denrzv/bloom-flowers).
- **Colmar Academy**, a 2018 practice project, is preserved on the
  [`archive/colmar-academy`](https://github.com/denrzv/denrzv.github.io/tree/archive/colmar-academy)
  branch.
